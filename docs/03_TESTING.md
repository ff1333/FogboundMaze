# 测试说明

## EditMode

`MazeCoreTests` 验证：

- 三种规模的迷宫都有起点到终点路径。
- 相同种子产生相同布局。
- 十关参数合法且机制按计划解锁。
- 十关布局指纹互不重复。
- 网格尺寸、候选数量和目标路线逐关提高。
- 实际选出的主路线长度逐关提高。

## PlayMode

`GameFlowTests` 验证：

- 主场景能够初始化到选武器阶段。
- 选择手枪后开始门打开。
- 进入游戏和到达出口会产生正确阶段变化。
- 能连续切换到第十关并生成安全灯。
- 第十关对象池按 14 个敌人的上限完成预热。
- 开始游戏后，敌人会经过出生预警再进入活动状态。
- 统一输入层能够驱动 CharacterController，并切换第一/第三人称视角。
- 第七关以后，玩家离开安全灯范围会受到瘴气伤害。

最终结果：`5/5 PASS`。

## Windows Player 烟测

开发包支持命令行 `-fogboundSmoke`。测试会在真实 Player 中启动场景、选择武器、
进入游戏、保存截图并退出。日志必须包含 `FOGBOUND_RUNTIME_SMOKE_PASS`，并且没有
C# 异常。

## 人工测试边界

自动化可以验证规则和流程，但不能替代手感判断。正式发布前仍要人工检查：

- WASD、鼠标、冲刺、攻击、换弹和视角切换。
- 手枪和砍刀各完成至少一次关卡。
- 雾、昼夜、精英、瘴气和安全灯能被看懂。
- Windows、浏览器和 Android 真机输入没有遮挡或失控。

文档不会把尚未执行的人工测试写成 PASS。
