# Fogbound Maze v1.0.1

> 历史版本：后续试玩已发现入口墙体堵路及边缘掉落问题。修复见 v1.0.2 与 `07_V1_0_2_ENTRY_FIX.md`，不再推荐发布或下载此版。

首次试玩问题修复补丁。`v1.0.0` 仍是原始版本；本次不改变十关迷宫、战斗与环境机制的范围。

## 改动

- 强化迷宫入口引导并修复走过入口偶尔不开始的情况。
- 调整第一/第三人称相机，加入中心准心和更清晰的手枪、砍刀攻击反馈。
- 选武器界面加入操作提示；`Esc` 可随时暂停并释放鼠标，暂停页提供返回选武器与可用平台的退出命令。
- 参考 Neon Arena 的紧凑信息层级，改进血量条、中央计时和弹窗边框。
- 提升迷宫可读性：墙脚线、入口灯光、出口门框与更均衡的照明。
- 新增逐格点亮的探索小地图，记录已走路径和朝向，不提前展示未探索通路。
