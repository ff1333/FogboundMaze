# v1.2.0：关卡说明与战斗表现迭代

日期：2026-10-03 至 2026-10-04。实现和自动验证由 Codex 辅助完成，用户新版真机验收另记。

## 第一轮：信息与反馈

- 开始页新增 FIELD GUIDE，浏览 1–10 关的机制、地图尺寸、刷怪间隔、敌人数、精英概率和安全灯参数。
- 图鉴读取 LevelCatalog 实际数值，不保存通关记录、不改变解锁、不直接进入关卡；Esc/BACK 返回开始页。
- 新增 Guide 阶段，禁止菜单内移动/攻击，关卡内选武器副标题提示本关重点。
- 枪口闪光、弹道线、命中火花、刀光采用共享材质和固定 64 个 LineRenderer；粒子上限 256。
- 增加命中 X、准星扩张回落、受伤边缘提示、换弹百分比、枪械下沉/回正及声音。
- 离开一局时清理特效、换弹协程和装备，避免新局残留。

## 第二轮：实际画面检查后的修正

第一次 Player 截图发现刀光占屏过大、枪口呈明显大星形。缩小闪光和刀光宽度、调整距离及枪口位置，
保留清楚反馈而减少遮挡。武器选择卡加入由实际模型离线渲染的缩略图，显示枪刀差异。
选武器框改为相对屏幕尺寸，文字不再承担图片的职责；修正按钮高亮乘色，保留浅色文字。
墙面增加浅支撑结构，仅作视觉层次，不新增阻路碰撞体；十关实体通路继续回归。

## 第三轮：边界与交付

- EditMode 10 项、PlayMode 23 项通过，包括旧版全部通路/存档/战斗回归。
- 新增图鉴访问不解锁、200 次弹道调用不扩容、特效过期、完整换弹及中途返回菜单验证。
- Windows 截图覆盖开始页、图鉴、选武器、枪口及刀光，另查 854×480 图鉴。
- 实际结果和截图保存在 `docs/test-results/v1.2.0/` 与 `docs/images/v1.2.0-*`；最终平台交付见 `10_V1_2_0_POLISH.md`。
- 安卓 SDK 联网检查曾阻塞；显式使用本机代理检查仓库、固定已安装 API 36 后继续构建。
  需保留最终 BuildReport 的告警数，不能把成功构建改写为零告警。

## 学习定位

`GameHud.Guide`：菜单与机制信息；`CombatEffects`：有限容量复用；`WeaponController`：实际攻击与换弹；
`GameHud`：事件反馈；`FogboundPreviewBuilder`：从现有模型生成可复现缩略图。
模型/原动画继续使用 Quaternius CC0，本轮没有声称原创建模、Mecanim、IK 或商业级美术。
共享缓存减少对象生成，但没有据此声称整局 0 GC 或固定性能提升百分比。
