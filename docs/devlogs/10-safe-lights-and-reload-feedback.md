# 试玩迭代 10：避难灯泄露路线与装弹完成反馈

日期：2026-10-04。目标版本：v1.2.2。
需求来源：作者试玩反馈；代码、自动验证与文档由 Codex 辅助完成，不冒充作者手工测试。

## 问题与取舍

旧 `MazeWorld.CreateSafeLights` 先求入口到终点的路径，再沿路径布灯，并在终点强制放灯。
这使环境提示泄露了解法。旧武器只有装弹开始声，完成后直接恢复弹药数字，完成时刻不够明确。
需求明确保留弹匣和装弹期间的脆弱窗口，不改成无间断连射。

## 迭代记录

1. 首轮尝试遍历全迷宫分支、每隔若干通道格放灯。自动测试发现第 7、9 关格子中心全部处于安全区，方案过密，未采用。
2. 改用固定种子打乱全图候选位置，再按至少 10 米间距放灯。支路和死路都有灯，生成过程不读取终点或正确路线。
3. 复用旧安全半径时，第十关沿中心线冲刺的理论瘴气耗血仍超过 100。将后期半径由 7→5 米调整为 7→6.25 米，保留伤害增长。完整采样结果见关卡平衡文档。
4. 新增独立的装弹完成机械声与 0.85 秒 READY 提示。射击清除提示，暂停冻结时间，死亡/换武器/返回菜单不会出现延迟补弹。
5. 更新第七关图鉴、设计文档和当前数值，清理“灯沿正确路线”与旧手枪参数的现行说明。
