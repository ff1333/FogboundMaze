# 03 - v1.0.0 多平台发布

## 本轮目标

把玩法完整版本收束为可复测、可构建、可上传的 `v1.0.0`，并明确自动化测试和人工
验收的边界。

## 发布阶段改动

- 将项目版本更新为 `1.0.0`。
- 增加移动输入、第一/第三人称切换和瘴气伤害的 PlayMode 覆盖。
- 为运行时相机补齐 `AudioListener`，避免 Player 中没有监听器。
- WebGL 使用 Gzip 和 Decompression Fallback，允许普通静态服务器正确加载。
- 增加 `Assets/link.xml`，防止 IL2CPP 裁剪运行时动态创建的 Collider 类型。
- 增加 Windows、WebGL、Android 一键构建和统一打包脚本。

## 本轮发现并解决的问题

### WebGL 压缩文件无法加载

第一次用普通 HTTP 静态服务器测试时，压缩 JavaScript 没有被服务器附带正确响应头。
开启 Decompression Fallback 后重新构建，浏览器可正常进入选武器界面。

### WebGL Collider 被裁剪

游戏通过代码动态添加 `SphereCollider` 和 `CapsuleCollider`。IL2CPP 无法仅靠静态引用
判断这些类型必须保留，导致 WebGL Player 报类型缺失。通过 `link.xml` 显式保留后，
错误消失。

### 输入测试受批处理帧率影响

最初测试用固定时间要求角色至少移动 0.5 米。在 `-nographics` 环境中，少量大时间步
让位移距离不稳定。测试改为出生准备区横向移动，只断言明确的水平位移，并独立验证
视角切换，消除了与帧率和重力无关的误报。

## 面试可讲的结论

“多平台完成”不等于只点击三次 Build。本轮实际处理了 WebGL 服务器压缩兼容、IL2CPP
代码裁剪、真实 Player 烟测和自动化测试稳定性问题。发布文档还把 Android 构建成功与
真机验证拆开记录，保证证据不会超过实际完成范围。
