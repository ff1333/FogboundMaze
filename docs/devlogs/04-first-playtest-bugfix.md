# 04 - 首次试玩问题修复与优化（v1.0.1）

## 试玩反馈与复现

这轮来自实际试玩反馈，不是新增关卡需求。`v1.0.0` 保留为原始发布记录，以下改动归入独立补丁版本 `v1.0.1`。

| 试玩现象 | 原因定位 | 修复与优化 |
| --- | --- | --- |
| 选完武器后不知道怎样进迷宫，偶尔走过入口也没有开局 | 起点门缺少醒目的方向提示，原入口触发范围偏窄，快速移动时可能错过触发 | 入口增加绿色门框、地面箭头和屏幕提示；扩大入口触发体，增加运动学 Rigidbody；玩家已装备且进入起点格时再做一次状态兜底 |
| 第三人称像俯视镜头，第一人称会被角色身体遮挡 | 原相机俯角和跟随高度不符合贴近角色的射击视角，角色模型没有按视角隐藏 | 第三人称调整为肩后机位，第一人称移到眼睛前方并隐藏角色身体；玩家朝向跟随相机水平方向 |
| 鼠标仍是箭头，没有准心，手枪射击难以判断命中 | 进入战斗时没有锁定鼠标，UI 没有中心瞄准反馈 | 装备后在桌面端锁定并隐藏光标；暂停、结算时恢复；增加中心准心、命中闪烁、枪口轨迹和后坐力 |
| 选刀后感觉无法攻击 | 原近战反馈弱，判定方向与镜头朝向不一致，目标可被自身/墙体检测干扰 | 增加可见砍刀模型与挥砍动作；按相机水平朝向做扇区和距离判定，使用视线遮挡检测；命中时显示反馈 |
| 不知道移动、攻击和切视角按键 | 选武器界面只有装备选项 | 在两个装备选项下方增加电脑/移动端各自的操作说明 |
| 鼠标变准心后无法随时退出 | 原暂停仅在正式进入迷宫后生效，装备后尚未进门的准备阶段按 `Esc` 无效；暂停页没有退出命令 | `Esc` 在已装备的准备阶段和战斗阶段都能暂停并释放鼠标；暂停页增加“返回选武器”，Windows/Android 增加“退出游戏”。WebGL 返回选武器后由浏览器关闭标签页 |
| 界面状态信息缺少层级，生命值变化不够醒目 | 迷宫原 HUD 把所有数值等宽排成文字 | 参考 Neon Arena 的紧凑顶栏：左侧 HP 数值与彩色血条、中央计时、右侧关卡与击杀；弹窗补细描边，但保留迷宫自己的青绿/警示橙配色和武器操作结构 |
| 迷宫墙地偏暗，普通走廊、入口和出口的视觉区分弱 | 基础环境光和手电光锥偏保守，墙面只在顶部有装饰线，出口只有柱状信标 | 扩大手电覆盖并适度提高白天/夜间基础照明；增加浅色墙脚线、入口局部光和出口门框。不改变雾的关卡解锁或安全灯判定 |
| 进入迷宫后容易反复迷路 | 第一人称和肩后镜头只能看到眼前走廊，原 HUD 没有已走路线或朝向参考 | 增加探索小地图：只点亮走过的格子与通路，未探索格只显示暗网格，不暴露完整路线；当前位置显示朝向，终点只在走到后标出；重试或切关清空探索记录 |

## 发布验收边界

以上是自动测试与 Windows Player 烟测，不等于玩家已在最终正式包上完成整关。`v1.0.1` 的 WebGL 浏览器交互和 Android 真机触控仍需使用对应最终包确认；未完成前不能在简历、Release 或面试中写成“全平台人工验收通过”。

面试时可按“用户反馈 -> 复现 -> 定位 -> 修改 -> 自动回归 -> Player 烟测 -> 人工验收边界”讲述本轮，而不是只说“优化了手感”。
