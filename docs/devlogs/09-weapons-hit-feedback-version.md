# 试玩修复：武器、碰撞反馈和版本一致性

日期：2026-10-04。实现与工具验证：Codex 辅助；新版手动真机验收：待用户确认。

## 复现与定位

- 用户报告左手武器、命中不够明显，以及标题显示 v1.0.1。
- 编辑器检查素材层级，发现 Pistol/Knife/SMG 都挂在 Middle1.L；属于原素材的左手持械设计。
- 版本脚本未写死 v1.0.1，两个磁盘配置均为 1.2.0。截图的编辑器运行值与磁盘不同；保留这一证据边界，不声称已复现当时所有加载步骤。
- 旧射击要求单次按下，弹匣 10 发；近战判定与视觉反馈不够一致。僵尸攻击只看距离，没有薄墙遮挡判断。

## 修改

1. 镜像角色视觉/动画，使用自带 SMG 网格；沿原刀刃方向拉长为长刀。保持碰撞体/输入不变。
2. 枪改为按住连射，22 伤害/30 弹匣/32 米上限；长刀 70 伤害、3.4 米前向范围，增加前摇。
3. 枪验证胸口到枪口、枪口到目标两段遮挡；长刀验证距离、夹角、可见性并按敌人去重。
4. 增加 HIT/ELIMINATED 确认、加强火花、受击停顿；受击闪白合并协程避免连续命中时闪白被提前清掉。
5. 标题显示与构建版本统一到 1.2.1；Android versionCode 7，避免覆盖原来 code 6 的候选包。

## 画面迭代中额外发现

- 新枪网格初始方向上下颠倒，调整模型局部旋转后重做预览。
- 火花曾处于枪身中段，改为编辑器从枪管前端顶点生成 Muzzle 挂点，运行时只读挂点。
- 检查发现 FBX 未开启 CPU Read/Write，因此没有在正式包中读取 mesh.vertices，避免只在编辑器能运行的错误。
- 第一人称长刀占屏过大，单独缩小显示比例，第三人称刀刃长度和攻击范围不受影响。
- 隐藏窗口曾无法得到有效屏幕截图，烟测改用实际相机 RenderTexture 和相机空间 UI 渲染，并确认文件存在。失败截图未算通过。
